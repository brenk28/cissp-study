# CISSP Study Kit

A self-contained browser-based study tool for the CISSP exam. No server, no dependencies — open the HTML files directly in any modern browser.

## Files

| File | Description |
|------|-------------|
| `index.html` | CAT-style practice exam |
| `flashcards.html` | Flashcard study tool |
| `questions.js` | Question bank (1,000+ questions, loaded by `index.html`) |
| `study_guide.md` | Comprehensive domain-by-domain study guide |

---

## Practice Exam (`index.html`)

Open `index.html` in a browser. No setup required.

### Features

- **CAT (Computerized Adaptive Testing)** — difficulty adjusts based on your performance, mirroring the real exam.
- **Domain targeting** — weak domains are weighted more heavily.
- **Confidence meter** — real-time Trending Pass / Borderline / Trending Fail indicator.
- **Post-exam review** — per-question feedback with explanations and domain breakdown.
- **Scenario questions** — multi-question scenario blocks matching real CISSP format.

### Exam Modes

| Mode | Questions | Early exit |
|------|-----------|------------|
| Quick | 30 | No |
| Standard (default) | 75 | No |
| Full Simulation | 100–150 | Yes (once confidence is determined) |

### Question Bank

- **969** standard multiple-choice questions
- **31** scenario groups totaling **93** scenario questions
- Covers all 8 CISSP domains across Easy / Medium / Hard difficulty levels

## Flashcards (`flashcards.html`)

Open `flashcards.html` in a browser. Click a card to flip it. Use the navigation buttons to move between cards.

## Study Guide (`study_guide.md`)

Open `study_guide.md` in any Markdown viewer (GitHub, VS Code, Obsidian, etc.) for a full domain-by-domain reference covering concepts, formulas, frameworks, and exam tips for all 8 CISSP domains.
